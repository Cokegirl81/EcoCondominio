# ♻️ EcoCondomínio

Protótipo de aplicativo desenvolvido para incentivar a reciclagem em condomínios residenciais.

## Objetivo

Promover a conscientização ambiental por meio de informações sobre reciclagem, coleta seletiva e práticas sustentáveis.

## Funcionalidades

- Página inicial
- O que reciclar
- Calendário de coleta
- Dicas sustentáveis
- Indicadores da pesquisa

## Tecnologias utilizadas

- Python
- Streamlit

## Projeto Acadêmico

Desenvolvido para a Atividade Extensionista do curso de Tecnologia em Ciência de Dados da UNINTER.
